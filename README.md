# FlipItNews-News-Classification

An NLP-based news classification application that automatically
categorizes news articles using a Bidirectional LSTM model.

## Features

- Text preprocessing and tokenization
- Bag of Words and TF-IDF feature extraction
- Word2Vec document embeddings
- Neural Network and LSTM model comparison
- Accuracy, precision, recall and F1-score evaluation
- Interactive Streamlit dashboard
- Category probability visualization

## Technology Stack

- Python
- Pandas and NumPy
- Scikit-learn
- Gensim
- TensorFlow / Keras
- Streamlit

## Project Structure

    app.py
    requirements.txt
    README.md
    artifacts/
        news_lstm.keras
        tokenizer.json
        label_encoder.pkl
        model_config.json

## Run Locally

Install the dependencies:

    pip install -r requirements.txt

Start the dashboard:

    streamlit run app.py

## Dataset

BBC News dataset containing news articles and their categories.

## Model

The application uses a trained Bidirectional LSTM model.
The model predicts a category from the article text and displays
the probability assigned to each category.

## Disclaimer

Predictions are generated by a machine learning model and may
not always be correct.
